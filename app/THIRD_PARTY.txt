Talking Head Cutroom internal candidate component notes

The render pipeline builds on the talking-head adaptation distributed in the owner's MoneyPrinterTurbo-Talking-Head starter. This archive includes the adapted editor modules it uses. It does not bundle the entire upstream application. Before public redistribution of this preview or its derivative, confirm the owner's distribution grant for the starter and chosen product terms. This is a development handoff.

The embedded Python runtime is CPython 3.12.10 for Windows x64. Original distribution: https://www.python.org/ftp/python/3.12.10/python-3.12.10-embed-amd64.zip
See runtime/LICENSE.txt. The Python distribution includes the notices for its bundled dependencies.

The Windows GUI bootstrap uses the distlib Windows launcher by Vinay Sajip. See notices/distlib-launcher.txt.
Source: https://github.com/pypa/distlib

The UI embeds a Latin subset of DM Sans. See app/ui/DM-Sans-LICENSE.txt. Characters outside that bundled subset use local fallback fonts.
Source: https://github.com/googlefonts/dm-fonts

Burned-in captions use DejaVu Sans Bold. See app/fonts/LICENSE.txt.
Source: https://dejavu-fonts.github.io/

The click, slide and chime WAV files are synthesized sounds from the owner's earlier animation and SFX project. No third-party song or audio recording is included. The examples are synthetic process-verification footage and narration.

FFmpeg and FFprobe are installed separately or provided by the user. The app invokes them as external processes. Compatible Windows Essentials builds: https://www.gyan.dev/ffmpeg/builds/

The internal Windows release includes a subset of ffmpeg-skill3.2.3 by kajisho5 (MIT): the delivery checker and shared library only. Original source https://github.com/kajisho5/ffmpeg-skill; see third_party/ffmpeg-skill/LICENSE and version-manifest.json for the copied file hashes. It does not include FFmpeg binaries or optional ASR/model weights.

The optional first-use local transcription installer downloads faster-whisper1.2.1 and its dependency wheels from PyPI and the multilingual small model from Systran/faster-whisper-small on Hugging Face. These are not in the core archive. Actual wheel versions/licenses and model revision/hashes are recorded under workspace/asr after installation. No recording is uploaded. Review their individual terms before redistributing installed dependencies.

Example/Technical example.mp4 is newly generated test imagery and a sine test signal with source-generated SRT, not a real presenter, software demonstration or licensed reference excerpt. It may be redistributed with this kit. It does not resolve the separate starter distribution grant above.

Optional video skill adapters (installed separately; not embedded in the EXE):
- artemnovitckii/claude-editing-skills, commit beff6b868a8c1bdfad8661bd8a298497e75568a3, MIT code by Artem Novitckii. Keep its LICENSE and font OFL notices with the upstream checkout. Its third-party photographs, sample footage and showcase previews are excluded from that software license and are not packaged here.
- heygen-com/hyperframes: new HTML bridge pinned to npm0.9.33; existing editing workflows use compatible0.8.52. Keep the notices supplied with those packages. GSAP and user assets are supplied locally at runtime; review their own distribution terms.
- awesome-claude-video-skills is a CC0 catalog. Its catalog license is included in the repo skill. Catalog project licenses and upstream security labels are independent; the list is not a bundle of audited engines.

Motion AI skill: copied from motion-ai14.2.0 with trailing whitespace removed from two Markdown lines, content/skills/motion, by Matt Perry. The upstream package declares MIT; source: https://github.com/motiondivision/ai-kit. The installed source hashes and package metadata are retained in .agents/skills/motion/UPSTREAM.json. No Motion+ example source, audit methodology or premium component implementation is bundled with this skill. This agent skill is separate from the pinned compositor runtime and its vendor notice.
