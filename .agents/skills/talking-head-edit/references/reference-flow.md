# Adapt reference flow to the current episode

Inspect the whole reference, not only its busiest seconds. Record source SHA256,
source ranges, what was actually observed and the reviewer's capabilities. ASR
is a draft; a sampled frame grid does not certify normal-speed motion or sound.

Use a flow grammar: promise → named item → screen context → actual action →
readable result → presenter/next point → the presenter's real CTA. These are
roles, not fixed durations or an effects quota. Record reference timecodes for
each influence. Label timings `observed`, `estimated_to_test` or `house_rule`;
keyframes inferred from MP4 are not original editor keyframes.

Rebind every cue to this episode's speech and screen source. Preserve complete
phrases, qualifiers and useful breaths. If the interface is slower than speech,
enter the screen earlier or hold its result longer; record the choice. Do not
copy reference rankings, price claims or promises into a different narration.

Store reference excerpts in the animation library with ownership/permission,
source ranges, crop and exact preview hash. Their text, people and branding stay
baked into the pixels. Inspect every frame of short excerpts for cropped content
and unwanted watermarks before admitting them as illustrations. They cannot
prove the current episode's software action. Native JSON/HTML templates remain
editable and need new text, anchors and real proof when reused.

Record proposed/final decisions against the same spoken phrase and source
timecode. Keep agent-experimental observations separate from editor-confirmed
correction pairs. More references, a lower training loss or a loaded checkpoint
does not establish better editing; compare unseen episodes at the same media,
renderer and listening level before changing the default preset.
