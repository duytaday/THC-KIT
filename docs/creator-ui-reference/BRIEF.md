# Cutroom UI reference and implementation brief

Use the supplied images as visual references for a creator-focused local video editor. Keep the existing first-cut and review workflow and the editing engine's real actions.

- Editor references 02 and 07–09: dark graphite workspace, compact top bar, media rail, large central preview, contextual side panel, and a lower timeline. In Cutroom, make the right panel the timed transcript and render only timeline content backed by real cut data.
- Mobile references 03 and 06: keep the preview and playback controls prominent; stack transcript and asset controls below it without horizontal page overflow.
- References 01, 04 and 05: use restrained violet, magenta and blue light, soft gradients, thin borders, rounded dark surfaces, and readable type. They are visual inspiration; account, pricing, collaboration, AI-chat and editing controls that Cutroom does not support must not be presented as working features.
- Import: recording first, then optional script, footage to include, style reference and niche. State what can appear on screen and which recording each input belongs to.
- Review: clearly label original versus edited video; preserve phrase seeking, caption correction, shot changes, version-specific review and export. The timeline must use real passage timing and be keyboard accessible.
- Preserve the existing launcher, local assets, offline font, batch workflow, state handling and engine API. Test the actual application with existing media at desktop and phone widths.
- Language: Vietnamese is the default for creator-facing controls. Provide a persistent English / Tiếng Việt switch in the top bar. Keep creator-provided filenames, speech and caption text in their original language.
