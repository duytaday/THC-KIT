## Filled example for a Vietnamese Docker tutorial

Audience: Vietnamese beginners deploying their first WordPress site. Format: a 45–60 second vertical Reel, 1080 × 1920, Vietnamese captions with English commands. Takeaway: the viewer sees how to start the provided Compose stack and verify the containers are running. Hook: open with the working site if the footage shows it. Required beats: identify the Compose file, show the exact command from the recording, then show the status output and load the site. Preserve the command as filmed and keep the output visible until a viewer can read the relevant line. If the recording lacks the site check, flag the missing shot. Ending: recap the verification step. No CTA for this example.
